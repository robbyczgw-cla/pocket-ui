# Retro style icons (`src/retro.rs`)

Thirteen 32 x 32 pictures for the Retro style's Settings categories and pause menu rows, made with PixelLab
(`POST /v2/create-image-pixflux`, text prompt only, no input image; ours under PixelLab's terms). Each prompt ended with
"16-bit game menu icon, bold simple shapes, bright colours, centered"; view "high top-down", "low detail", "basic shading",
"single color black outline", no background. Requests and seeds: `pixellab-log.jsonl`. Not touched by hand.

| File | Prompt |
|---|---|
| look.png | a small wooden painter's palette with red, blue and yellow paint blobs and a brush |
| sound.png | a chunky retro loudspeaker box with a round speaker cone |
| playing.png | a retro game controller with a cross d-pad and two round buttons, grey and purple plastic |
| games.png | a grey retro video game cartridge with a blank cream paper label |
| connections.png | a small portable transistor radio with a tall silver antenna |
| system.png | a simple chunky metal cog wheel icon (test call `t-gear32`) |
| help.png | a small red metal toolbox with a handle |
| continue.png | a round green button with a white play triangle |
| save.png | a blue floppy disk |
| load.png | an open yellow folder with a paper sheet inside |
| options.png | a crossed wrench and screwdriver |
| quick.png | a bright yellow lightning bolt |
| quit.png | a bright red door standing half open with warm light coming out of the doorway |
