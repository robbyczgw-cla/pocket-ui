# What pocket-ui expects of a ROCKNIX system: the data of scripts/rocknix-contract.sh, explained row by row in
# docs/ROCKNIX-CONTRACT.md. One row per promise:
#
#   kind|label|where pocket-ui relies on it|path in the system (no leading /)|argument
#
# The argument is the rest of the line (it may contain |). Kinds:
#   file       the path exists (alternatives separated by ;)
#   absent     the path does not exist (an override that would change what pocket-ui relies on)
#   exec       an executable file
#   grep       the file has a line matching the extended regular expression in the argument
#   fn         001-functions-style file <path> defines the shell function <argument>
#   body       <file>:<function>: the function's body has a line matching the argument
#   keys       the script reads every system.cfg key of the argument (get_setting, game_setting, add_setting)
#   cfg        the file (ROCKNIX's default system.cfg) has the key <argument>=
#   sha        the file's sha256 is one of the argument's (versions the launcher knows)
#   calls      the ROCKNIX functions (defined in the argument's first word) the script calls are all among the rest
#   lockstyle  wait_lock in the file takes the lock in a way src/system_cfg.rs knows (create-exclusive or flock)
#   trips      ROCKNIX's fancontrol trip temperatures for a profile: "<profile> t1 t2 t3 t4 t5 t6"
#   sys        es_systems.cfg's system <path>: "<folder> <extensions...>" as in ROCKNIX 20261001, or "-" (not there)
#   sysroot    every system folder in es_systems.cfg starts with the argument's first word, but those of the systems
#              named after it (Tools, Music and the like)
#   core       <path>/<argument>_libretro.so is there
#   text       a fixed string in a (binary) file; the path's last part may be a shell pattern
#   glibc      the C library at the path is at least the argument's version
#   systemd    systemd (libsystemd-shared-<n>.so in the folder) is at least the argument
#   live:KIND  only on a running system (--host); n/a on a folder or a source tree
#   src        not a check: for --ref, where the file at <path> comes from in ROCKNIX's source tree (the argument;
#              alternatives separated by ;, the first one there counts, for files that moved in the tree)
#
# Some rows are kept in step with the code by cargo test (os_compat::tests::the_rocknix_contract_data_matches_the_code):
# the sha rows (os_compat::KNOWN_UI_START), the file rows of os_compat::FILES and DLOPEN, the core rows
# (hostsys::routed_cores), a sys row for every system name of hostsys, the lock and the path of system_cfg, the keys of
# setsettings.sh and input_sense (emu_choice::RA_SETTINGS, fn_keys::KEYS), and the trips rows (fan_curve). Every row
# needs its line in docs/ROCKNIX-CONTRACT.md (the_rocknix_contract_doc_lists_every_row). The sys rows are ROCKNIX
# 20261001's es_systems.cfg.
