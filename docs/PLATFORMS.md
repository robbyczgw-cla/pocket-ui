# What each platform has

One table of what a player can use, taken from the code and the docs (0.4.1). "Not seen" means the code has it but nobody has
watched it on that platform's real device. ROCKNIX handhelds are the reference: every feature below was seen there, unless its row says otherwise.
Android is supported by its own launcher and player.

| Feature | ROCKNIX handhelds | Android |
|---|---|---|
| Insert animations (the console takes the game) | yes | yes, at the phone's pixels (emulator) |
| Continue (open cases: A goes straight back to the saved moment) | yes | yes (emulator) |
| Kids mode | yes | no: not in scope, the Android app has no such mode |
| Game check | yes | yes (emulator); no "hide a twin" fix |
| Second card (copying games without Wi-Fi) | yes, where the handheld has a slot | no |
| "Sign in…" for a Wi-Fi that wants a sign-in page | yes | no |
| PSP ISOs of any size in the built-in player | yes | yes (emulator), a first start copies the game into the app and needs that much room; other systems' games up to 512 MB |
| Cabinet and TV | yes, with multi-shelf navigation | yes (emulator), with shelves for recent games, favourites and each system in the Shelf and Cabinet looks; TV beside the cases in landscape |
| Case stickers | yes, editable | yes (emulator), the five case stickers; no Curator stickers of your own |
| Memory card (pause menu) | yes | yes (emulator) |
| Game connections | yes | yes (emulator) |
| Pause menu | yes | yes, touch and controller looks |
| Achievements | yes | no |
| Screen frames | yes, all built-in frames | only the small Console and CRT TV surrounds |
| Spanish | yes | in the code, not seen |
| Second card with games | H700 handhelds (their second slot), from ROCKNIX's automount and device trees | no |
| USB file transfer | retired (not offered; the code stays) | no |
| File sharing and its row on Add games | yes | no |
