# Controls in Settings, setup and on the touch screen

The second half of [Controls](controls.md): the buttons in Settings and its pages, during setup, on the touch screen,
and the power and volume keys. The Mini V2's picture, the shelf, games, the pause menu and Options are on
[the first page](controls.md).

## In Settings

Settings opens on five categories (Look & feel, Playing, Games, Connections, System); each holds a short list
([Open Settings](settings.md#open-settings)).

| Button | What it does |
|---|---|
| D-pad Up / Down | Move. The list wraps around at the ends. |
| A | On a category: open its list. In the list: open. On Language, Haptics, Sounds, Animations, On start, Remember where I quit, Button layout and Screen frames: switch. |
| D-pad Left / Right | On Sounds: how loud. On Language, Animations, On start, Button layout and Screen frames: switch. |
| B | In a category's list: back to the categories, the one you came from selected. On the categories: back to where you came from (the shelf, or a system's game list). |

A page of Settings (Wi-Fi, Tools, Battery and the others below) goes back with B to its category's list, even when
it was opened from somewhere else.

### In Wi-Fi

| Button | What it does |
|---|---|
| D-pad Up / Down, L1 / R1 | Move, one or five rows at a time. |
| A | Connect (a saved network without its password), or open Other network… / Wi-Fi country. On a network that has said **Not answering** for a minute: type its password again. |
| Y | Forget the selected saved network. Y again confirms, B keeps it. |
| X | Scan again. |
| B | Back. |

The keyboard is described in [Getting started](getting-started.md#4-connect-to-wi-fi).

### In Tools

| Button | What it does |
|---|---|
| D-pad Up / Down, L1 / R1 | Move, one or five rows at a time. |
| A | Start the tool. A tool that changes or sends something asks first: A again starts it, B keeps it closed. |
| X | Look for the tools again. |
| B | Back to its category's list in Settings. |

### While a tool runs

| Button | What it does |
|---|---|
| HOME, held for a second, then let go | Stop the tool and come back to Settings → Games → Tools. |
| L1 held + SELECT + START | ROCKNIX's way to close a tool, for the tools that support it (the page says which). |

Everything else belongs to the tool. There is no pause menu.

| B | Back. While the PIN shows: stop pairing. |

## Touch screen

The touch screen works next to the buttons; it never does anything a button can't.

On the shelf, the game lists, Settings, the search and the game switcher:

| Touch | What it does |
|---|---|
| Tap a row (or card) | Select it. Tap the selected one again to open or play it. |
| Swipe up / down | Scroll the list: the selection follows the finger by whole rows. The list stops at its ends. In the manual the page follows the finger. |
| Swipe left / right | On the Cards look and in the game switcher: previous / next card. In the Cabinet: along the shelf (up / down: to another shelf). |
| Tap a button hint at the bottom (A, B, X, Y, SELECT, START) | The same as pressing that button. START opens Settings. |
| Tap a key of the search's keyboard | Type it. |
| Tap a Curator row on a game's card (Echoes, Versions, Stickers) | Select it. Tap it again to open it. |
| Tap Up next on the shelf | Play that game, as A does. |

In a game, pocket-ui ignores the touch screen and the game gets it:
- **Nintendo DS**: touch the bottom screen with a finger as you would with the stylus. It follows the layout in use
  (one above the other, side by side). Touching the top screen, or anywhere beside the picture, does nothing.
  The right stick and R2 still work as a pointer, if you prefer them.
- Other systems ignore it.

The quick settings and the power menu can be touched, even over a paused game: a row selects it, the selected
one does what A does, the arrows round a value are Left and Right, and the hints at the bottom are their buttons.
The pause menu and the first-start setup are button-only for now. Touching the screen keeps the device awake (it
counts like a button), but a touch never wakes a sleeping screen.

If the touch screen does not answer: pocket-ui looks for it until it is there, and opens it again if it was lost
(after a restart of the touch driver, say), so it comes back by itself. Touches are also dropped on purpose while a game
or app runs, while the screen is off or the Pocket sleeps (only a button wakes it), on the pause menu and the first-start
setup, and while the picture is on a TV. Which one it was is in the log (`/var/log/pocket-ui.log`, lines starting
`touch:`); Settings → System → About → Report a problem includes it.

## Power and volume

| Button | What it does |
|---|---|
| Power, short press | Sleep. In a game, the game is saved first and goes on where it was when you wake the device. Press Power again to wake it. Or, when set so, **Screen off**: only the screen goes dark and the game goes on. |
| Power, held for about a second | Opens the **power menu**. Letting go after that does not also put the device to sleep. Or, when set so, **Sleep** when you let go. The **Power…** row of the [quick settings](quick-settings.md#quick-settings) opens the same menu; B there goes back to the quick settings. |
| Power, held for many seconds | The device's own forced reset, without saving. pocket-ui leaves it alone: use it only when nothing responds. |
| Vol+ / Vol- | Volume. With START held: brightness. With SELECT held: colour temperature. |

Sleep starts when you let go of the button, not when you press it: that is how a short press is told
from a held one. A short press never opens a menu, and the press that wakes the device does nothing else.

What the short press and the hold do is set in Settings → System → **Sleep & power**
([Sleep & power settings](quick-settings.md#sleep--power-settings)).

### Volume and brightness keys

These work on the shelf, in quick settings and in games. A bar at the top of the screen shows the level.

| Keys | What it does |
|---|---|
| Vol+ / Vol- | Volume |
| START + Vol+ / Vol- | Brightness, in steps of 5%, never below 5% |
| HOME + Vol+ / Vol- | Brightness (ROCKNIX does the change, pocket-ui shows the bar) |
| SELECT + Vol+ / Vol- | Colour temperature, warmer or colder. There is no setting page for it |

RetroArch games and the standalone emulators get no bar; the changes still apply. The colour temperature reaches
RetroArch, PlayStation 2, GameCube and PortMaster games only when the screen supports it system-wide.

### The power menu

At the top right: the battery level and the time left, as on Settings → Playing → [Battery](settings.md#battery).
Under each entry, a line says what it does.

| Entry | What it does |
|---|---|
| Sleep | Saves the running game and puts the Pocket to sleep (the same as the default short press). |
| Restart | Saves the running game, then restarts the device. pocket-ui comes back and opens the game again. |
| Power off | Saves the running game, then switches the device off. |
| Restart pocket-ui | Saves and closes the running game, then starts only pocket-ui again, in a few seconds; the system keeps running. pocket-ui comes back and opens the game again. For when a screen seems stuck, without restarting the whole device. |
| Restart to boot menu | Restarts into the bootloader's menu, where you can switch the boot mode to Android (choose **Switch boot mode**, then Android, then **Start**). Only shown when the device can do that. Without it, the menu says how to get to Android by hand: Power off, then hold Vol Down + Power and choose Switch boot mode. |

| Button | What it does |
|---|---|
| D-pad Up / Down | Move. |
| A | Choose. |
| B, or the Power button again | Close the menu. In a game, the game goes on where it was. |

In a game, the menu pauses it first, like the pause menu does (the pause menu is open behind it).
Closing the menu puts the game back; choosing Sleep puts it back and then sleeps, so the game goes on
after waking.
